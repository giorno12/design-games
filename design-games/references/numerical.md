## 1. 数值设计顺序

先确定体验目标，再定数值：目标击杀时间、遭遇时长、容错次数、资源稀缺度、成长节奏、构筑差异和付费边界。数值模型用于逼近目标，不是用“表格闭合”代替体验。

始终写明：单位、基准等级、输入范围、舍入、上下限、加算/乘算顺序、快照/动态更新、期望/分位/最坏情况和假设。连续近似与离散结算分开。

## 2. 战斗公式

### 期望伤害与 DPS

若每次攻击独立，命中率 `a`，命中后基础伤害 `D`，暴击率 `c`，暴击倍率 `m`，且未命中无伤害：

`期望单次攻击伤害 = a × D × [1 + c × (m - 1)]`

`期望 DPS = 期望单次攻击伤害 ÷ 攻击间隔`

这里不含装填、移动、护甲、溢出伤害、目标切换和动作取消。实际项目按结算顺序扩展，不能把期望当每发保证。

### 减伤与有效生命

若减伤率为 `r`，则 `有效生命 EHP = HP ÷ (1-r)`，仅适用于该伤害类型且 `0≤r<1`。

常见非负护甲模型：伤害倍率 `K ÷ (K + Armor)`，则 `EHP = HP × (K + Armor) ÷ K`。K 控制护甲收益尺度，不是跨游戏通用常数。

### 击杀时间

持续伤害近似：`TTK = HP ÷ DPS`。离散攻击需考虑每次伤害、溢出、前摇和首发时刻；含随机命中/暴击时给分布或模拟，不只给平均。治疗、护盾、阶段无敌和目标切换另建模型。

### 相对强度

比较两个方案时固定目标、时长、资源与操作假设。看伤害之外的范围、可靠性、机动、控制、风险和机会成本。对关键断点做敏感性分析，例如多一段攻击能否少一击击杀。

## 3. 概率和保底

独立单次成功率 `p`，重复 `n` 次至少成功一次：`1 - (1-p)^n`。恒定独立概率下期望次数为 `1/p`，但玩家会经历长尾，不能只报期望。

达到置信度 `C` 所需次数：`ceil(log(1-C) ÷ log(1-p))`，适用于 `0<p<1`。

软保底必须定义从第几抽开始、每抽如何递增、是否截断、硬保底位置及成功后是否重置。用完整分布报告期望、中位数、P90/P99 和硬保底占比。实际商业随机机制还需核查目标地区现行披露和监管要求。

## 4. 成长与经济

### 成长曲线

- 线性：`Cost(L) = Base + Step × (L-Start)`，增长稳定。
- 几何：`Cost(L) = Base × g^(L-Start)`，易形成长期倍率膨胀。
- 多项式：`Cost(L) = Base × (L/BaseLevel)^Power`，便于调节中后期斜率。

曲线形状不直接等于体验。结合解锁、内容消耗、玩家能力、失败成本和实际获得速度检查。

### 经济账户

按人群、版本和时间窗记录：资源期初、各来源、各去向、转换、损耗、期末。`净流量 = 总来源 - 总去向`。分别看新玩家、活跃玩家、重度玩家和付费分层，不用全局平均掩盖分布。

经济系统需定义： faucets、sinks、存量、交易、绑定、产出上限、找回、复制防护和异常回滚。通胀不只是“总量上升”，还要观察购买力、价格、持有分布和内容可及性。

### 付费与奖励

避免用模糊概率、强迫性倒计时、无限追赶或操控弱势玩家替代游戏价值。付费强度与竞技公平、内容可及性和未成年人风险需要独立评审。

## 5. 平衡、模拟和数据表

### 平衡流程

基准对象 → 目标区间 → 公式模型 → 内容批量生成 → 极端组合检查 → 模拟 → 内部测试 → 分层玩家数据 → 单变量或小组合调整 → 回归。

50% 胜率不等于平衡。按水平、地图、阵容、选取率、先后手和样本量分层；区分强度、流行度、克制、学习成本和体验问题。

### 模拟

模拟用于探索分布、极端组合和敏感性。记录随机种子、版本和假设；至少报告样本数、期望、标准差/分位和最坏样本。不要把模拟玩家当真实玩家行为。

### 数据表最小字段

稳定 ID、版本、启用状态、类型、等级、基础值、成长参数、上下限、标签、前置、来源、去向、备注和校验错误。禁止用手写行号充当长期引用；显示名与逻辑 ID 分离。

### 数值工具

在技能目录运行 `python scripts/design_math.py --help`。提供期望 DPS、EHP、连续 TTK、独立掉落、线性软保底分布和帧率无关阻尼计算。复杂模型应复用函数或另写可复现模拟，不要手改输出结果。
