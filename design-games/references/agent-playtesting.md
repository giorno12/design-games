# AI 代理游玩与自动化测试

以视觉-语言-动作（VLA）模型驱动的 AI 代理直接「看屏幕、动键鼠」玩游戏，用于回归测试、平衡验证和可测试性设计。代表工作：米哈游 Gamer（arXiv:2611.18397，2026-11）及其 CPT 基座 GameScaling（arXiv:2610.28698）。

## 1. 能力边界：代理现在能玩什么

先分清代理的能力层级，别把演示当现货：

- **跨游戏持续预训练（CPT）基座**：只有通用操作本能（认画面、会键鼠），没有具体游戏的策略知识。实测（保卫萝卜4，GameScaling-2B，消费级硬件）：能稳定输出合法动作、会移动光标，但三次实跑未建一座塔——「会操作」不等于「会玩」。
- **加指令微调（SFT）**：能跟随任务指令、在关键节点推理、用记忆摘要跨上下文续任务。
- **加在线强化学习（RL）**：才是演示里的水平。Gamer-RL 在《崩坏：星穹铁道》支线任务里程碑完成率 80%+，在 40 个未见过的小游戏上平均成功率 49.7%（CPT 基座只有 15%）。

其他已验证事实：

- **负迁移**：训练数据混合偏离目标游戏时，堆更多不相关数据不提升目标游戏表现。垂直游戏要先录本游戏数据。
- **暂停表现 ≠ 实时表现**：暂停下评测高分的策略，实时运行时可能因「动作到达时状态已变」而大幅退化。评估代理必须在与部署一致的实时条件下进行。
- **长流程靠记忆摘要**：单局超过上下文窗口时，代理靠自我生成的摘要（已完成/失败/计划）延续任务，而非记住全部历史。

结论：代理今天适合做**可自动核验的回归与冒烟**，不适合替代真人判断「好不好玩」。玩家测试仍是体验结论的唯一来源。

## 2. 为「可被代理游玩」而设计

设计阶段预留这些条件，事后补的成本高一个数量级：

- **可验证里程碑**：任务/关卡进度有环境侧可查询的状态（任务 ID、阶段、完成标记）。强化学习和自动评测都依赖可核验结果；没有核验信号，代理只能看图说话，无法自动变强。
- **关键状态视觉可读**：血量、资源、当前目标在屏幕上稳定可读——代理和人类玩家吃同一套视觉信息，UI 对代理可读通常也意味着对玩家更清晰。
- **UI 流程稳定**：按钮位置、菜单层级、交互链少变。UI 改版 ≈ 已训练策略失效，改版要排代理回归。
- **决策间隔宽容**：消费级硬件上小模型单步决策约 5–8 秒。回合制、可暂停、慢节奏玩法对代理友好；帧级反应玩法当前不可用。设计验收场景时按「游戏允许的最大决策间隔」选型。
- **机器可读规则摘要**：代理的系统提示词需要准确的游戏规则与键位文本。事实性错误（横竖屏、UI 位置、机制有无）会直接误导代理行为。设计文档里维护一份与实现一致的规则摘要，人和代理共用。

## 3. 生产管线应用

- **回归冒烟**：版本构建后代理自动跑关键关卡，检出卡死、死路、崩溃、资源断链。失败轨迹（画面+操作序列）即复现材料。
- **平衡性漂移监控**：固定种子/固定构建，比较版本间通关率、时长、资源结余的漂移；小样本只报趋势不报结论。
- **新手引导验证**：代理只凭规则文本游玩；它的失败模式会暴露规则描述与引导的缺口（实测：提示词里写错一处事实，代理行为立刻跑偏）。
- **无障碍参考**：纯键鼠代理的输入约束 ≈ 运动障碍玩家的输入子集；代理玩不通的路径值得人工复核。
- **不适用**：手感、情绪曲线、叙事体验、付费设计、美术感受——仍需真人测试与评审。

## 4. 接入协议与预算

Gamer 公开的交互协议（可直接复用）：

- 输入：每 200ms 一帧画面（5Hz），附最近若干帧历史与任务指令。
- 输出：每个 200ms 块 = 一次鼠标位移（屏幕宽高的千分比）+ 6 组 33ms 按键状态，键表 74 个 token。同一块支持点按、长按、拖拽与组合键。
- 提示词契约：游戏名 + 规则 + 键位映射三个槽位；输出格式段落与训练时逐字节一致，不能改写。

预算与实测坑：

- 官方实时推理（65ms/步）基于 H200 级硬件；消费级 Apple Silicon 跑 2B 模型约 5–8s/步。先定决策间隔预算，再倒推模型规模与硬件。
- 执行端：触屏映射窗口（模拟器、iOS App）识别不了过短的按压，鼠标键需 ≥100ms 保持；窗口未聚焦时第一次点击会被聚焦吃掉；必须提供急停（如故障保护区）。
- 评估时每个构建跑多局：采样温度下单局方差大，单局结论不可靠。

## 5. 数据采集与微调

- **轨迹格式**：画面帧与设备事件按统一动作表示对齐（5Hz 观察 / 30Hz 动作）。原始轨迹里 85%+ 是重复动作，需重复衰减降权；按键频率偏置用随机键位重映射消除。
- **指令数据三级**：局部操作 / 中间子目标 / 完整任务，同一套观察-动作接口；用 LLM 辅助在关键决策点标注推理、在上下文边界标注记忆摘要。
- **长流程强化学习**：按记忆摘要把长局切段，同阶段跨局比较可核验结果，功劳按时间衰减分配到段内决策（TA-GRPO）。
- **最便宜的起步**：目标游戏录数十小时真人轨迹做 SFT，通常比堆通用数据有效；GPU 预算按模型规模查当期行情，不写死。

## 6. 风险与红线

- Gamer 官方定位为学术研究，明确禁止用于作弊、未授权访问、破坏公平。把代理接入任何联网游戏前，先确认该游戏用户协议与法务意见。
- 在自有单机/内部构建上测试无此风险，但要用隔离的测试账号，避免反作弊误判波及正式账号。
- 代理产出的「通过率」是工程指标，不是体验指标；不要用代理全勤替代真人试玩节点。
